# 📊 HR Analytics Dashboard
An interactive HR Analytics Dashboard built using **Power BI** to analyze employee data and identify key attrition trends.
## 🎯 Features
- Total Employees
- Active Employees
- Attrition Count & Rate
- Average Age & Experience
- Attrition by Department
- Salary Slab Analysis
- Job Satisfaction Analysis
- Age Group Distribution
## 🛠 Tech Stack
- Power BI
- Power Query
- DAX
- Excel
